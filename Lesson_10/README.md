# Автоматизация тестов: Интернет-магазин и Калькулятор 

Это учебный проект, в котором написаны автоматические тесты для двух сайтов: интернет-магазина (SauceDemo) и калькулятора с задержкой вычислений.

Проект построен по правилам **Page Object Model (POM)**. Это значит, что логика работы с элементами сайтов отделена от самих тестов и лежит в папке `pages`.

---

## 📂 Структура проекта

* 📁 **`pages/`** — папка с описанием страниц (слой элементов и действий):
  * `__init__.py` — служебный файл для правильной работы папки как пакета.
  * `base_page.py` — базовый класс, где настроены умные ожидания элементов.
  * `shop_page.py` — все кнопки, поля и действия для интернет-магазина.
  * `calc_page.py` — логика взаимодействия с кнопками и экраном калькулятора.
* 📁 **`tests/`** — папка с тестами:
  * `test_shop.py` — тест сквозного сценария покупки 3-х товаров.
  * `test_calc.py` — тест вычислений на медленном калькуляторе.
* 📄 **`conftest.py`** — настройки запуска браузеров (Firefox для магазина, Chrome для калькулятора).
* 📄 **`pytest.ini`** — файл настроек, чтобы pytest знал, где искать тесты и куда сохранять отчеты.

---

##  Правила оформления кода в проекте

1. **Аннотация типов (Type Hinting):**
   * Для всех функций и методов (кроме `self`) указаны типы данных. Если метод принимает текст, написано `text: str`, если число — `seconds: int`.
   * В конце каждого метода указано, что он возвращает (`return`). Если метод просто кликает по кнопке и ничего не возвращает, написано `-> None`. Если считывает текст — `-> str`.

2. **Оформление отчетов Allure:**
   * Каждый тест снабжен красивыми ярлыками (декораторами): `@allure.title` (название теста), `@allure.description` (описание), `@allure.feature` (какой блок тестируем) и `@allure.severity` (важность теста).
   * Все действия внутри тестов и проверки (`assert`) обернуты в блоки `with allure.step("...")`. Благодаря этому в итоговом отчете каждый шаг виден отдельно.

## Как запустить тесты и посмотреть отчет

### Шаг 1. Запуск тестов
Откройте терминал в PyCharm и введите простую команду для запуска всех тестов:
```bash
pytest
```
*Благодаря настройкам в файле `pytest.ini`, результаты для отчета автоматически соберутся в папку `allure-result`.*

### Шаг 2. Открытие отчета в браузере
Чтобы собрать результаты в красивый интерактивный отчет и открыть его, введите:
```bash
allure serve allure-result
```
После этого автоматически откроется ваш браузер со всей статистикой, шагами и результатами тестов. Чтобы закрыть отчет и остановить сервер, нажмите **Ctrl + C** в терминале.
